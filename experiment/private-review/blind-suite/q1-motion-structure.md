# Private Review: Q1 Motion Structure

Expected answer:

- Q1 tests whether static-scene ego-motion creates structured image motion that can support correspondence reasoning.
- A good answer says the signal is physically meaningful enough to justify later projection/correspondence tests.
- Q1 does not validate learned features, dense correspondence, triangulation robustness, or control.
- It helps rule out the trivial failure that image motion is unstructured or unrelated to camera motion.

Known bad answers:

- "Q1 proves dense 3D perception."
- "Q1 proves the feature model works."
- "Q1 validates control."
- "No later geometry tests are needed."
