# Probe: Next Prior Selection

Read the current audit and selected failure reports. Propose exactly one next
physical prior to test. Here, "physical prior" means a bottom-level embodied-AI
physical rule or constraint to start from, not general research discipline.

Answer:

1. Which current failure does the prior target?
2. What is the minimal claim?
3. What prototype would test the claim?
4. What would falsify the claim?
5. Which tempting modules should not be added yet?
